# Gaurav Kumar — Premium Developer Portfolio

A responsive, animated personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `gaurav-premium-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email address.
- Add your profile photo in `assets/images/` and update the hero section if desired.
- Add verified project repository/demo URLs to the relevant project cards.
- Add certificate images in `assets/certificates/`.
- Add your final resume PDF as `resume.pdf` and create a download link if needed.

## Notes
- The project uses Google Fonts over the internet; a system fallback is provided.
- The contact button currently opens the visitor's email app. A real contact form requires a backend or form service.
- Project visuals are CSS illustrations, not screenshots of actual applications.
- Verify all personal details and project features before publishing.
